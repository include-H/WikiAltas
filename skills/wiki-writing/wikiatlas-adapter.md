# WikiAltas 宿主适配说明

仅在任务明确涉及 WikiAltas 的字段、关系、工作区或正文落库时读取本文件。普通的作品 Wiki 写作不需要本文件；这里的内容不能反过来改变文章的结构和文风。

## 1. 事实与对象

- 已生效的载体正文存于 `media_entries.wiki_content`，版本字段为 `content_version`。
- 已生效的系列主文存于 `works.summary`，版本字段为 `summary_version`。
- `media_entries` 是关系图中的站内载体节点；`works` 负责作品树归属和系列主文。
- 外部服务对象、页面、OST、攻略和访谈不是关系图节点；它们只能作为外站关联或检索材料。

宿主字段只描述身份、关系或存储状态，不替代正文中的事实。条目内容仍按 `core.md` 和介质文件写。

## 2. 正文提交

所有正文变更统一使用 `ContentCommit`：

- 目标可以是一个 `entry` 的 `wiki_content`，或一个 `work` 的 `summary`；
- 每个 mutation 带读取时的 `expectedVersion`；
- 请求使用 `Idempotency-Key`，服务端在一个事务中校验版本、更新正文、写历史并更新全文检索读模型；
- 子条目与父系列主文需要一起更新时，作为同一命令中的主 mutation 和明确的索引回写 mutation；
- 版本冲突返回冲突信息，不做无证据的三方合并。

LLM 正文遵循 B1：终稿由服务端自动提交，提交成功即生效。`draft.ready` 只表示草稿就绪，不能当作已保存；只有 `content.committed` 才表示正文已写入并可重新读取。回滚也是一次新的正文提交，不删除历史。

结构、身份、外站关联和归档属于另一条流程。不要把正文润色伪装成结构改动，也不要直接拼 SQL——
**结构与关系都有对应的工具**（见 §4），走工具，不要绕到库上去。

## 3. 当前关系词典

WikiAltas 冻结的关系类型及方向如下（**与代码里的 `ValidRelationTypes` 一致**，别的写法会被工具拒绝）。
只在来源足够明确时创建关系：

| 类型 | 方向 | 含义 |
| --- | --- | --- |
| `adaptation_of` | 改编作 -> 原作 | 改编关系 |
| `sequel_to` | 续作 -> 前作 | 后续作品 |
| `spin_off_of` | 衍生作 -> 来源作 | 衍生关系 |
| `remake_of` | 重制或重拍作 -> 原作 | 重制/重拍关系 |
| `expansion_of` | 扩充/续写/另一结局 -> 原作 | **同一段故事的另一种讲法** |
| `references` | 引用或致敬作 -> 被引用对象 | 引用/致敬关系 |
| `same_series` | 同系列作品互指 | 仅当树结构表达不出来时才建 |

关系只存一条有方向的边，反向文案由读取侧计算；不允许自指、环或指向不存在的节点。

**建条目时顺手把边落了**（`upsert_relation`）：同一段故事的续写、改编、衍生、另一结局，
不落边的话，读取侧只看到"旁边还有另一部"，看不出它们讲的是同一件事——回答跨作品问题
（某角色的结局、某个设定）时就不会去连带那一条。

## 4. Agent 上下文与工具

宿主可按当前页面和任务暴露以下工具：

- `read_wiki`：读取指定 entry 或 work 的正文；跨对象时传明确 ID；
- `rag_search`：定位站内片段，命中后再用 `read_wiki` 精读；
- `search_web`：检索外部来源；
- `fetch_url`：读取已允许的搜索结果页面；
- `read_skill`：按需读取本 skill 的入口或子文件。

工具可用范围由运行时决定。没有暴露某个工具时，不要凭空假设它存在，也不要把工具名写进正文。上下文应只包含当前目标、相关兄弟条目和必要来源，不要把整库清单当作写作材料。

## 5. 宿主交付检查

若任务明确要求落库，交付前确认：

1. 正文目标和 `expectedVersion` 来自同一次读取；
2. 正文提交与结构提案没有混用；
3. LLM 终稿以 `content.committed` 为成功信号；
4. 关系词、方向和目标节点符合当前词典；
5. 未把外源 API、文件路径、旧项目名或临时对象写入正文；
6. 适配层没有把某一部作品升级为全局写作规则。

## 6. 外部库边界

GameAtlas、Emby、Komga 等外部媒体库是可选集成，不是写作前提。外部元数据只能在用户明确要求同步时按该集成的最新契约处理；本适配说明不提供端点、字段映射或自动同步假设。没有明确契约时，完成正文即可，不发起外部写入。
