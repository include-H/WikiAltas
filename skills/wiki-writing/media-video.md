# 影视介质补充

写电影、剧集、动画、OVA/OAD、剧场版条目时读这一份。骨架、题记、文风、事实核查、边界和通用自检都在 `core.md`，这里只写影视特有的部分。

## 1. 本篇取的章名

- 第 3 章 = 故事背景与设定
- 第 5 章 = 叙事与影像特色
- 第 6 章 = 主要角色与创作团队，最后一节固定是核心关系简述
- 动画在第 6 章末尾加一节 `主要创作团队`：原作、系列构成、角色设计、动画制作、音乐

## 2. 一篇条目覆盖到哪

默认：一个有独立发行身份、能完整看完的影视产品 = 一篇。

| 情况 | 默认做法 |
| --- | --- |
| 一部电影的院线版 / 加长版 / 导演剪辑版 / 未分级版 | 同一篇，差异写进 2.2 |
| 一部剧集或动画的多季 | 整部一篇，剧情按季或故事弧分节 |
| 剧场版、特别篇、OVA/OAD | 发行身份或叙事体量足够独立时另立一篇，否则进 2.2 |
| 重拍（remake）、重启、叙事独立的衍生剧 | 各自独立成篇 |
| 换配音、换发行渠道、画质重制 | 不是新作，进 2.2 |

同名作品、不同重拍、按季拆分时，标题里加年份、季次或版本限定：`作品名（2011）`、`作品名 第二季`、`作品名（TV动画）`。标题要让读者一眼知道说的是哪一个产品。

## 3. 2.1 字段清单

共用：原名、中文名、别名、制作地区、题材、子类型、叙事结构、内容属性、导演、编剧、制片、出品或发行方、主要演员或声优、片长或单集时长、首映或首播日期、关联作品、主要奖项。

- 剧集追加：季数、集数、播出平台、播出周期、完结状态。
- 动画追加：原作、系列构成、角色设计、动画制作、放送季度、话数、主题曲（OP/ED 曲名与演唱者）。

## 4. 标签分四类，不要串维度

- **题材**：作品总体属于什么（剧情、犯罪、科幻、奇幻、动画……）
- **子类型**：更细的形态（黑色电影、法庭剧、职场、偶像、太空歌剧……）
- **叙事结构**：单线、多线、非线性、多视角、单元剧、章回式
- **内容属性**：年代、群像、成长、社会写实、黑色幽默……

```
- 题材：剧情
- 子类型：法庭剧、社会派推理
- 叙事结构：多线、非线性
- 内容属性：年代、群像、社会写实
```

标签要短、可拆分、可复用；不要把一整句评价塞进字段，也不要把技术名词或宣传语当成叙事结构。

## 5. 2.2 要区分清楚的东西

- 电影：院线版 / 导演剪辑版 / 加长版 / 重映 / 修复版——都是同一部；remake 是另一部。
- 剧集：季 / 季中特别篇 / 季终 / 衍生剧 / 前传剧。
- 动画：TV / 剧场版 / OVA·OAD / 总集篇 / 海外播出版 / 影碟修正版。

每条都要说明这个版本对内容、时长、制作团队、发行日期或观看顺序有什么实际影响。不要把发行渠道、配音语言、画质升级自动写成新作；没有依据时不要把特别篇算进正篇集数。

## 6. 非线性与多视角

先说明播放顺序和故事时间线哪里不同，再决定第 4 章按时间线、按视角线还是两者并列组织。

- 按真实时间线重述时，标出观众在哪一刻才拿到某项信息；
- 保留银幕顺序时，说明每次跳转的作用；
- 同一段里不要无提示地混用两条轴线。

## 7. 第 5 章常见小节

叙事结构 / 摄影与视觉 / 剪辑与节奏 / 音乐与声音 / 表演与场面调度 / 与源作品的差异（改编作必写）。

每节写具体手法 + 使用场景 + 可观察的结果：

- ❌ 摄影很有电影感，配乐非常震撼。
- ✅ 室内戏几乎只用窗外自然光，人物半张脸常在暗部；同一段弦乐动机分别出现在开场葬礼和结尾法庭，把两场戏扣成一组。

## 8. 第 6 章的角色行写法

有演出阵容时，全篇统一用一种形式：`角色名 —— 演员或声优：说明`，或 `角色名（演员 饰）：说明`。每个角色 1–2 句，写身份 + 在故事结构中的作用。

群像作品按阵营、家庭或故事线分组。完整 cast 表、客串名单、幕后名单不进正文，需要时放参考资料或独立资料页。

## 9. 影视增量自检

在 `core.md` §8 之外再确认：

- 标题能区分版本、重拍、季次和特别篇；
- 2.2 说清了版本边界，没把再发行写成新作；
- 集数、季数、片长、首播日期、主创都有来源；
- 剧情按季、幕或故事弧组织，非线性轴线已说明；
- 影像分析有手法和场景，不是泛泛赞美；
- 第 6 章没有退化成完整演员表，客串和龙套没进正文；
- 动画的原作、系列构成、角色设计、动画制作已写清。
