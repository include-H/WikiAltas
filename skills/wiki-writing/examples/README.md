# 样例校准说明（离线专用）

**这份文件仅供离线回归评测与人工校准，运行时模型不读。** 它记录逐篇样例的合格判定与已知偏差，用来在改动 skill 后对照检查信息密度、证据落点、章节职责和语气有没有回退。

改 `core.md` / `SKILL.md` 前先跑一遍这些样例留下基线，再改（`core.md` §8 末尾）。

## 已知偏差

- **分隔线**：多数样例的章节之间有 `---`。当前规则里可有可无，但同一篇要一致。
- **题记署名**：`上古卷轴_V_天际` 的引用题记缺署名行。引用式必须补署名。
- **介质偏斜**：6 篇里 4 篇是游戏，**没有电影、真人剧、小说**。样例的章名与写法不能跨介质套用，按 `core.md` §2.2 取名。

## 题记逐篇判定

样例的题记可作写法参考，但并非篇篇合格，**不能当格式范本**：

| 样例 | 题记类型 | 判定 |
| --- | --- | --- |
| `007_初露锋芒` | 场景式 | 合格 |
| `16bit的感动` | 引用式 | 合格 |
| `风之谷（漫画）` | 引用式（整段引用 + 空行） | 合格 |
| `上古卷轴_V_天际` | 引用式 | 勉强（缺署名行） |
| `仙剑奇侠传_1995` | 诗句式 | 勉强 |
| `现代战争` | 引用式 | 勉强（署名不全） |

判定依据以 `core.md` §4 的规则为准；规则与样例冲突时以规则为准。

## 逐章常见写坏方式（缺陷日志）

从 `core.md` §3 体量表移出的失败记录，供人工校对时对照；不是写作规则。

| 章 | 最常见写坏方式 |
| --- | --- |
| 1 概览 | 写成剧情简介，或写成跨载体总目录 |
| 2.1 基本资料 | 字段值里塞判断句 |
| 2.2 版本关系 | 把移植、再发行、配音版写成新作 |
| 2.3 核心卖点 | 写成宣传语 |
| 2.4 关键词 | 写成短句而不是词 |
| 3 背景设定 | 提前复述剧情；开始评价好坏 |
| 4 剧情概要 | 流水账；只写到中段；用「最后真相大白」收束 |
| 5 创作特色 | 「镜头很美」「系统丰富」 |
| 6 角色与团队 | 退化成完整演员表 |
| 7 评价与定位 | 只写「口碑很好」 |
| 8 一句话总结 | 复读第 1 章 |
| 9 参考资料 | 列没用过的来源 |
