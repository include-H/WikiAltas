# 结构化字段（可选）

只在任务明确要求机器可读的身份、别名、关系字段时读这一份。任务没要求就只写正文。

字段是正文之外的**索引层**：它承载身份、检索和关系，不承载剧情、评分、ISBN、发行日期——那些仍写在正文对应章节。字段也不能反过来决定文章写什么：先定内容范围，再补字段。

## 1. 默认字段与取值

宿主已经声明枚举时用宿主的；没有宿主契约时用下面这套默认值，并在交付说明里写明用了默认值。

```yaml
medium: game            # movie / drama / anime / manga / novel / game
aliases:
  - 可检索的正式译名
relations:
  - type: adaptation_of
    target: <能唯一指向一个对象的标识>
    note: 改编范围或限定条件
```

- **medium**：一个条目只有一个 medium。同一 IP 的不同载体是不同条目，不是同一条目挂多个 medium。
- **aliases**：只收可检索、且确实指向本条目的名称（正式译名、港台译名、常见简称、原名）。**不要收兄弟载体或其他作品的名字**，那会让检索把两个对象混成一个。
- **relations**：每条只描述两个明确对象之间的一个事实关系。
- **来源**：别名和关系也需要来源。不确定就留空或标 `待核实`，不要用肯定语气掩盖。

## 2. 关系方向：先定 from 和 to

关系只存一条有方向的边，反向说法由读取侧推导。默认语义：

| 语义 | 方向（from → to） |
| --- | --- |
| 改编 | 改编作 → 原作 |
| 续作 | 续作 → 前作 |
| 衍生 | 衍生作 → 来源作 |
| 重制 / 重拍 | 重制作 → 原作 |
| 受启发 | 受启发作 → 启发来源 |
| 引用 / 致敬 | 引用方 → 被引用对象 |

- 关系词和方向必须与宿主词典一致；宿主有自己的枚举时以宿主为准（WikiAltas 的词典见 `wikiatlas-adapter.md` §3）。
- 不要用一个模糊的「相关」代替具体关系，也不要为了让关系图好看而猜关系。
- 不允许自指、成环或指向不存在的对象。
- 目标对象必须能被唯一识别；识别不了就报告悬空目标，不要顺手创建新对象。

## 3. 边界

- 不把外部页面 URL、文件路径、临时 ID、某个应用的内部状态写成通用字段。
- 关系的新增、修改、删除是独立的结构动作，不能夹在正文润色里悄悄带过。
- 新增字段名、枚举值或关系词之前先查宿主契约；冲突时以宿主契约为准。

## 4. 自检

- 每个值都能说出来源和用途；
- 别名没有把兄弟载体或不同版本误合并；
- 关系方向与关系词一致，目标唯一可识别；
- 正文事实、外部服务字段、未确认对象都没有混进字段；
- 宿主需要审批、版本或幂等信息时按适配说明执行，没有在这里自创流程。
