# 游戏介质补充

写游戏条目时读这一份。骨架、题记、文风、事实核查、边界和通用自检都在 `core.md`，这里只写游戏特有的部分。

## 1. 本篇取的章名

- 第 3 章 = 世界观与背景设定
- 第 5 章 = 玩法与结构特色
- 第 6 章 = 主要角色与势力，最后一节固定是关系简述（可写 `势力关系简述`）
- 2.2 有 DLC 或资料片时可写 `版本与 DLC 关系`；完全没有附加内容就用 `版本关系`，或删掉重排

## 2. 标签分四类，不要串维度

- **题材**：大体属于什么，如角色扮演、动作、策略、视觉小说
- **子类型**：玩法或结构的细分，如动作角色扮演、第一人称射击、即时战略、回合制、卡牌构筑、章节式冒险
- **视角**：玩家主要用什么镜头看世界，如第一人称、第三人称、俯视、横版、等角
- **内容属性**：叙事主题或表现气质，如校园、悬疑、科幻、黑暗奇幻、恋爱、历史

```
- 题材：角色扮演
- 子类型：动作角色扮演、章节式冒险
- 视角：第三人称
- 内容属性：黑暗奇幻、神话改写
- 游戏模式：单人
```

单人、多人、合作、竞技属于**游戏模式**，不是视角。标签要短、可拆分、能独立看懂；不要把一整句宣传语拆成词堆进字段，也不要把引擎名或画面技术写成视角。

## 3. 2.1 字段清单

原名、中文名、港台译名、常见简称、制作地区、开发商、发行商、导演或游戏总监、制作人、首发平台、发售日期、游戏模式、题材、子类型、视角、内容属性、引擎（有可靠来源才写）、系列定位、关联前作或续作、主要奖项、分级或内容提示。

平台移植、区域发售日期差异、版本差异集中写在 2.2，不要塞进 2.1 的字段值。

## 4. 第 3 章：世界观写「世界怎么运转」

交代时代、地点、社会结构或世界规则、核心冲突，以及玩家角色在这个结构里的位置。

- 战争题材：写冲突格局和各方立场；
- 幻想题材：写规则、势力与神话；
- 科幻题材：写技术及其社会后果。

这一章不复述剧情，也不用结局解释主题。

## 5. 第 5 章：写玩家实际怎么行动

按作品取舍这些维度：关卡或地图结构、任务编排与探索路径；核心战斗、潜行、驾驶、经营或解谜循环；角色成长、装备、资源与难度；叙事与玩法的结合（分支、时间循环、调查、对话选择）；多人、合作、竞技或附加模式的独立规则；相比同系列前作新增、删减或转向的机制。

每节给出机制名称 + 运行方式 + 玩家感受到的结果：

- ❌ 战斗系统丰富，操作流畅，自由度极高。
- ✅ 潜行被发现后不直接失败，而是进入 15 秒的搜索阶段，玩家可以反打、逃脱或改道；这让「被发现」变成节奏切换而不是重开存档。

机制名和数值只有在来源或可复核的游戏内材料支持时才写。

## 6. 第 4 章：剧情按可解释的推进单位分节

按主线阶段、章节、阵营线或任务弧分节，小节标题点出该阶段发生了什么。不要逐关复述任务目标清单；需要列任务时先给阶段概括，再保留少量能说明结构的节点。

多结局或分支作品：先说明有哪些线、分歧点在哪，再分别写各线的走向和收束，并说明哪条是官方正史（有依据才写）。

## 7. 第 6 章：角色 + 势力

先写读者必须认识的角色，再写支撑冲突的势力、组织、家族或阵营。每条 1–2 句写身份和作用；角色多时按阵营或功能分组。行格式全篇统一：一般用 `角色名：说明`，有值得列的真人或配音阵容时用 `角色名（演员 饰）：说明`。

最后一节用一小段串起 2–3 条关键关系链，把角色表接回剧情。

## 8. 2.2 要区分清楚的东西

| 一组概念 | 判定 |
| --- | --- |
| 原版 / 加强版 / 导演剪辑版 / 高清复刻 / 重制 / 重启 | 改了故事、关卡、系统或发行身份就说明具体差异；重启另立条目 |
| 本体 / 独立资料片 / 扩展包 / DLC / 季票 / 合集 | 说明是否需要本体、是否改变主线、内容量级 |
| 跨平台移植 / 区域版本 / 云版本 | 不是新作，只写平台与日期差异 |
| 只改分辨率、语言、打包方式的再发行 | 不是新作，一行带过 |

同名作品会混淆时，显示名加年份或版本限定。

## 9. 游戏增量自检

在 `core.md` §8 之外再确认：

- 四类标签互不串维度，游戏模式没有被写成视角；
- 版本、资料片、DLC 与移植关系没有混写；
- 世界观、玩法、剧情、评价四章各自承担不同信息，没有互相复述；
- 剧情按阶段组织，结局与分支按用户要求写清；
- 第 6 章没有退化成完整角色图鉴，势力有定位；
- 机制名、数值、平台发售日期、奖项都完成了对应强度的核查；
- 兄弟载体（改编影视、漫画、小说）只在 2.2 留接口，没有搬进来。
